# 🟡 Nivel intermedio

Este nivel aplica la **construcción voraz aleatorizada con múltiples inicios** a problemas de selección, distribución y recorridos. Son ejercicios  orientados a la práctica de laboratorios.

El énfasis está en proponer criterios de evaluación, mantener soluciones factibles y comparar correctamente sus resultados.

## 🎯 Objetivos

Al finalizar este nivel deberías poder:

- identificar y justificar un **criterio de evaluación**
- construir la RCL únicamente con candidatos factibles
- actualizar capacidades, cantidades y asignaciones
- distinguir objetivos de minimización y maximización
- reconocer y descartar construcciones incompletas cuando corresponda
- analizar cómo influyen `α` y la cantidad de iteraciones

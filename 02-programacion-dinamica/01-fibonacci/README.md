# 🐇 Fibonacci con Programación Dinámica

🟢 **Dificultad:** Básica · 🧠 **Técnica:** Top-Down y Bottom-Up · ⏱️ **Tiempo:** O(n) · 💾 **Espacio:** O(n)

## 📝 Enunciado

Dado un número `n`, implementa dos funciones que calculen el n-ésimo número de la serie de Fibonacci aplicando **programación dinámica**: una con el enfoque **Top-Down** (recursión con memoización) y otra con el enfoque **Bottom-Up** (tabulación iterativa). Ambas deben evitar recalcular subproblemas ya resueltos.

## 🧪 Ejemplo de ejecución

Para `n = 7`, el programa debería imprimir el resultado de cada enfoque:

*Solución Top-Down:* 13<br>
*Solución Bottom-Up:* 13

La primera línea corresponde a la solución Top-Down y la segunda a la solución Bottom-Up.

## 🚧 Restricciones

- Se deben implementar **ambos enfoques**: Top-Down (memoización) y Bottom-Up (tabulación).
- La solución Top-Down debe **almacenar los resultados ya calculados** para no repetirlos.
- La solución Bottom-Up debe resolverse de forma **iterativa**, construyendo la tabla desde los casos más pequeños.
- La complejidad temporal de ambos algoritmos debe ser **O(n)**.
- La complejidad espacial de ambos algoritmos debe ser **O(n)**.

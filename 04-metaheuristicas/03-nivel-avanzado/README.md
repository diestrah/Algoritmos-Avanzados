# 🔴 Nivel avanzado

Este nivel reúne problemas que requieren combinar varias decisiones, restricciones y criterios de evaluación.

La dificultad se centra en **modelar correctamente el problema** y adaptar la construcción a situaciones como la doble RCL, los recursos múltiples y las dependencias entre candidatos.

## 🎯 Objetivos

Al finalizar este nivel deberías poder:

- coordinar **dos RCL** dentro de una misma construcción
- gestionar varios recursos simultáneamente
- evaluar soluciones mediante objetivos como **maximizar un mínimo**
- incorporar dependencias que habilitan nuevos candidatos
- distinguir la evaluación de una elección de la calidad de la solución completa
- justificar las decisiones de diseño y reconocer sus limitaciones

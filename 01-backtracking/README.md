# 🔙 Backtracking

Explorar todas las posibilidades de un problema **construyendo la solución paso a paso**, y **deshaciendo** la última decisión cuando ese camino no lleva a ninguna parte.

> 🔁 Hacer → Explorar → Deshacer

## 🎯 Objetivos

Al finalizar estos ejercicios deberías poder:

- 🌳 representar un problema como un árbol de decisiones
- ✅ identificar el caso base de cada problema
- ↩️ aplicar el patrón **hacer, explorar y deshacer**
- ✂️ podar ramas que no pueden llevar a una solución
- 🧩 generar todas las soluciones y también contarlas o encontrar solo una

## 👀 Estrategia

Antes de programar, **dibuja el árbol de decisiones** de un ejemplo pequeño. <br>
Verás de inmediato dónde está el caso base y dónde conviene podar.

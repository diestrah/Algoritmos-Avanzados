# 🟢 Nivel básico

Este nivel introduce los fundamentos de la **construcción voraz aleatorizada**, como preparación para resolver problemas con GRASP.

La progresión comienza con una elección entre candidatos, continúa con la construcción de una solución completa y termina con múltiples construcciones para conservar la mejor.

## 🎯 Objetivos

Al finalizar este nivel deberías poder:

- construir una **lista restringida de candidatos (RCL)**
- comprender el efecto del parámetro de relajación `α`
- seleccionar candidatos aleatoriamente y actualizar el estado
- distinguir una elección de una construcción completa
- repetir construcciones y conservar la mejor solución

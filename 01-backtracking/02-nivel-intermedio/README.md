# 🟡 Nivel intermedio

Este nivel se enfoca en aplicar backtracking sobre **matrices y tableros**, donde las decisiones dependen de la posición.

## 🎯 Objetivos

Al finalizar este nivel deberías poder:

- recorrer una matriz probando varias direcciones
- marcar y desmarcar celdas visitadas
- validar si una posición es segura antes de avanzar
- decidir cuándo parar en la primera solución y cuándo contarlas todas

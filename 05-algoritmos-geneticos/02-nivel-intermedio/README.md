# 🟡 Nivel intermedio

Este nivel adapta los **algoritmos genéticos** a problemas de selección, asignación y recorridos, utilizando distintas representaciones y restricciones.

## 🎯 Objetivos

Al finalizar este nivel deberías poder:

- elegir una representación adecuada para cada problema
- definir funciones de evaluación para maximización y minimización
- seleccionar padres mediante ruleta o torneo
- trabajar con cromosomas binarios, bloques de bits, genes enteros y permutaciones
- adaptar el cruce y la mutación al significado de los genes
- detectar aberraciones y eliminar clones
- conservar soluciones válidas durante el reemplazo

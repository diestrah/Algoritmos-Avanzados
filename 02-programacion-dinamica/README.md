# 🧩 Programación Dinámica

Resolver un problema grande a partir de subproblemas más pequeños, **guardando sus resultados para no recalcularlos**. 💡

> 🔁 Si un subproblema se repite, ¡guárdalo!

## 🎯 Objetivos

Al finalizar estos ejercicios deberías poder:

- 🔍 identificar subproblemas que se repiten en un problema
- 📐 definir el caso base y la relación de recurrencia
- ⬇️ aplicar el enfoque **Top-Down** (memoización)
- ⬆️ aplicar el enfoque **Bottom-Up** (tabulación)
- 🗂️ construir y leer tablas de estados (arreglos y matrices)
- 🪶 reducir el espacio utilizado cuando la solución lo permite

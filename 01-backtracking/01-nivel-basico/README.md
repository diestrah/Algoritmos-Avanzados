# 🟢 Nivel básico

Este nivel se enfoca en generar soluciones aplicando el patrón **hacer, explorar y deshacer**.

## 🎯 Objetivos

Al finalizar este nivel deberías poder:

- generar subconjuntos, permutaciones y combinaciones
- identificar el caso base de una recursión con backtracking
- aplicar podas simples para descartar caminos inválidos

# Programación Dinámica

Este repositorio reúne ejercicios de programación dinámica en C++. 
La idea central es resolver un problema grande a partir de subproblemas más pequeños, guardando sus resultados para no recalcularlos.

## Objetivos

Al finalizar estos ejercicios deberías poder:

- identificar subproblemas que se repiten en un problema
- definir el caso base y la relación de recurrencia
- aplicar los enfoques Top-Down (memoización) y Bottom-Up (tabulación)
- construir y leer tablas de estados (unidimensionales y matrices)
- reducir el espacio utilizado cuando la solución lo permite
